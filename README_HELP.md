# Run the AI Website

1. Open the project folder in VS Code.
2. Double-click `run_server.bat` or run this command in PowerShell:

```powershell
cd "c:\Users\DELL.COM\Desktop\ai chatbot"
C:\Users\DELL.COM\AppData\Local\Microsoft\WindowsApps\python3.13.exe server.py
```

3. Open this link in your browser:

- http://127.0.0.1:8000/index.html

If the page says the assistant is unavailable, make sure the server is still running in the terminal.
